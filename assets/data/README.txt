Files the converters read at runtime. PsychApiLibrary.hxc is the Psych Lua API written in HScript, embedded into converted V-Slice scripts. Loaded with Platform.resourceBytes("data/<name>").
introText.txt holds the title screen jokes, one per line, the two halves split by "--" like FNF's introText.txt.
ui/ holds title.json, mainMenu.json and backButton.json, which set the images, positions, animations and timing of the title screen, the main menu and the back button. ui/README.txt lists every key.
