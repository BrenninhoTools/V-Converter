The V-Converter project officially recognizes the Simplified Chinese translation developed and maintained by YLuzew.

This community-maintained localization makes V-Converter more accessible to Chinese-speaking users while preserving the original application's functionality.

Compatibility

The Chinese localization modifies only user-facing text strings.

The following components remain unchanged:

- Conversion logic and functionality
- Generators and conversion systems
- File formats and output structures
- Core application behavior

Mods generated using the Chinese version are equivalent to those generated by the original V-Converter.
