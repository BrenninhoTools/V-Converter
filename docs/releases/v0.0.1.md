# V-Converter v0.0.1

The first release of V-Converter: a native Android and Windows app that converts Friday Night Funkin' mods between **Psych Engine**, **V-Slice** and **Codename Engine**, and creates new V-Slice content with built-in editors.

> This app was vibe coded: the code was written with an AI assistant (Claude) from prompts, then tested against the engines' source code. Please open an issue if something breaks.

## Downloads

| File | Platform |
| --- | --- |
| `V Converter-Android.apk` | Android 8.0 or newer |
| `V Converter-Windows.exe` | Windows 10 or newer (installer) |

## Converter

- **Five directions**: Psych → V-Slice, V-Slice → Psych, Codename → V-Slice, Codename → Psych and Psych → Codename.
- **Whole mods** from a folder or a `.zip`, `.rar` or `.7z` archive, with songs, variations, audio, characters, stages, weeks, scripts, events, note types and images, downloaded as a `.zip` or written straight into a mod folder.
- **Charts**: previews before and after, conversion options and faithful timing, events, note kinds, scroll speeds and difficulties in every direction.
- **Characters**: pixel-exact offsets with the spritesheet XML, Animate atlas characters, player/opponent/girlfriend sides and game over characters.
- **Stages**: props, layers, scroll factors, animated sprites, character positions and cameras, including stages built in Lua.
- **Weeks and levels** with freeplay icons, colors and menu characters.
- **Scripts**: Lua and HScript converted to V-Slice `.hxc`, Psych HScript or Codename HScript, with the Lua API mapped (sprites, tweens, timers, cameras, shaders, gamepads, saves and more) and custom events and note types moved to the right folders.

## Generator and editors

- **Chart Editor**: start a song or open any V-Slice, Psych or Codename chart. V-Slice style grid with the base game note sprites, music playback with split voices and hitsounds, events with typed fields and an icon, BPM and time signature changes, difficulties, snapping from 1/4 to 1/192, undo/redo, a mini-map of the whole song, and export to V-Slice, Psych or Codename with the audio.
- **Character Editor**: open any character or a bare spritesheet, play its animations, drag offsets with a ghost of the idle, edit camera, scale, side and health icon, and export to all three engines with the spritesheet.
- **Stage Editor**: open any stage with its images, select and drag props and characters, edit layers, scroll, scale, alpha and angle with the game camera frame in view, and export to all three engines with the images.
- **Mod, Level and Script generators** for new V-Slice mods, story weeks and `.hxc` classes.

## App

- Original FNF-style icon, the Funkin font, a custom cursor (also shown where you touch on phones), `freakyMenu` menu music and `scrollMenu` click sounds.
- Options under the gear: FPS counter, touch cursor, UI sounds, menu music and its volume.
- The Windows app shares every converter and editor with the Android app, with drag and drop and keyboard shortcuts in the editors.
