# V-Converter v0.0.2

V-Converter now runs on **Android, iOS, Windows, Linux and macOS**, comes with an online server (mod gallery, live rooms for editing together) and a PlayTest mode, and converts scripts into the real V-Slice classes.

> This app was vibe coded: the code was written with an AI assistant (Claude) from prompts, then tested against the engines' source code. Please open an issue if something breaks.

## New platforms

- **iOS and iPadOS**: the full app (converters, editors, PlayTest, online) with a side menu on iPhone and the sidebar on iPad. Files open from the Files app, mod folders are read and written in place and `.zip` results are saved through the Files export sheet.
- **Linux** (`.deb` and a portable folder) and **macOS** (`.dmg` and `.app`).
- A new icon.

## Converter

- **Scripts become the standard V-Slice classes**: song scripts extend `Song`, stage scripts extend `Stage`, note types extend `NoteKind` (carrying their note style), custom events are a single `SongEvent` and global scripts stay `Module`s, named after their ids. A script only falls back to a scoped `Module` when its class can't hold it, and the report says why.
- **V-Slice → Psych** leaves out code that needs classes Psych 1.0 doesn't have (listed line by line in the report) and turns `VideoCutscene.play` into `startVideo`.
- Better V-Slice stage and script conversion, including `FunkinMemory` caching.

## Generator and editors

- **Week Editor**: open or create V-Slice, Psych and Codename weeks with a live story menu preview, songs, menu characters and unlock settings.
- **Character Editor**: the stage behind the character and an accurate game camera.
- **Multieditor**: edit a chart, character, stage or week together with other people in live rooms, public or private, with shared images and audio.
- **PlayTest**: play any song of a mod, a converter's result or the Chart Editor's chart with its stage and characters, with botplay and a report of what is broken.

## Online

- A V-Converter server (in `server/`) with a mod gallery, update checks, announcements, error reports and live rooms. Set its address in the options.

## Notes

- The Android APK is signed with the same keystore as v0.0.1, so it installs as an update.
- The macOS app isn't notarized: the first time, right-click it and choose **Open**.
- RAR and 7z archives can't be opened on iOS or Apple Silicon Macs; extract them first or use a `.zip`.
