# V-Converter v0.1.0-playtest

The first PlayTest build of 0.1.0: V-Converter now also runs in the browser, the whole app looks and works like Friday Night Funkin's menus, logs in with Discord and shows your status on Discord, and writes mods in the V-Slice Public PlayTest layout.

> This app was vibe coded: the code was written with an AI assistant (Claude) from prompts, then tested against the engines' source code. Please open an issue if something breaks.

## Web

- **V-Converter in the browser**: the converters, editors, PlayTest and online features run on Kotlin/Wasm. Files stay on your computer and every result downloads as a `.zip`.

## Menus

- **Title screen** like FNF's TitleState: the intro text on the beat (with a random joke from `data/introText.txt`), then Girlfriend dancing, the bumping logo and "Press Enter to Begin"; Enter, Space or a tap skips the intro and starts.
- **Main menu** like FNF's: CONVERTER, GENERATOR, ONLINE and OPTIONS over the menu background, with the flicker on confirm, keyboard, mouse wheel and touch.
- **Converter and Generator lists** in the Alphabet font, like the options menu: pick a conversion (Psych to V-Slice, Codename to Psych and the rest) and then what to convert, or pick an editor.
- **Export menu like FNF's pause menu**: Export in the Chart, Character, Stage and Week editors now opens over the editor with the Alphabet font: pick the engine with left and right, then Export, Save To Mod Folder or Save As Zip (they export first when needed) and PlayTest for charts, with the target, file list, warnings and status on screen.
- **FPS counter everywhere**: it now shows on every screen (title, menus, editors, Online), in the top-left like FNF by default. Options → FPS Counter picks FPS only, FPS + Memory (average and worst frame time, 1% low, refresh rate, memory and its peak) or FPS + Graph (the last 120 frames), the corner, colors when the FPS drops and a background box.
- **Chart and Character converters in FNF style**: the Charts and Characters tabs of the converter now open a Freeplay-style menu with the Alphabet font. Every file is a row with its health icon (left and right pick the player, opponent or girlfriend slot for characters), plus Preview (before and after the conversion), Options (song name, artist, stage, speeds, difficulty names), Convert, Save To Mod Folder, Save As Zip and PlayTest. Delete or a long press removes a file.
- **Mod converter in FNF style**: the Mod tab is now a Freeplay-style menu too: Open Mod Folder, Open Archive, the mod's songs (left and right look through them), Mod Info (title, description and author in the FNF options menu), Install Into Mods Folder, Save As Zip, Cancel while it converts, Report (left and right pick each part, with the warnings), PlayTest, Test In Friday Night Funkin', Clear and Back. The top right shows the mod, its root and what was found; the conversion scanner shows at the bottom right.
- **GameBanana in one click**: the mod converter menu has a GameBanana item that browses Friday Night Funkin' mods (Popular, New, Updated, search, or a pasted GameBanana link). Enter or a second tap downloads the mod's newest clean archive and opens it in the converter right away; a long press shows every file to pick another one.
- **Scripts converted by V-Script (C++)**: Psych Lua scripts are now rewritten by a new C++ converter straight into the V-Slice class they belong to (Stage, Song, Module, NoteKind or SongEvent). Sprites become typed fields, `setProperty`/`getProperty` become the real object paths, tweens, timers, sounds, cameras and characters use the V-Slice and Flixel calls directly, and Psych callbacks become the matching V-Slice event overrides. No Psych API layer is generated any more. The script generator and the built-in Psych event classes use it too; the web build keeps the old converter.
- **Converted scripts run in the game**: scripts were checked against the real Funkin source. Every override is `public override function`, sprites use `FunkinSprite.create` and `loadTexture`, animations use `playAnimation`/`getCurrentAnimation`/`isAnimationFinished`, Stage scripts build in `onCreate` and run `onCreatePost` once the characters exist, and sprites behind or in front of the characters are placed with zIndex at runtime so they no longer cover the characters. SongEvents take `SongEventData`, and the calls that do not exist in V-Slice (like `Type.enumIndex`) were removed.
- **Charts, characters and stages converted in C++**: the Psych to V-Slice chart, character and stage converters now run in V-Script (C++) on desktop, Android and iOS, with the Kotlin converter as fallback (and on the web). Both give the same files. Characters and stages are written as version 1.0.2, and Psych's "Set GF Speed" event becomes V-Slice's `SetTargetBopSpeed`.
- **Chart events detected and scripted automatically**: the chart converter now finds the Psych events V-Slice has no built-in for (Change Character, Add Camera Zoom, Screen Shake, Set Property, Play Sound and Alt Idle Animation) and always keeps them, even with "keep unknown events" off, writing the matching `scripts/events/*.hxc` SongEvent next to the song. The report lists every one with its script. **Change Character** (or `ChangeCharacter`) now really swaps the character in game: the new character is preloaded at the countdown, placed by the stage, gets its health icon, and the original comes back on retry.
- **Faster mod conversion with V-Archive (C++)**: ZIP mods are now read in place instead of being extracted to a temporary folder first, and files that go unchanged into a ZIP output (songs, images, videos) are copied with their compressed bytes as they are, with no decompress and recompress. Folder outputs extract straight from the ZIP, folder inputs are added to the ZIP by native code, and song charts are written to their final V-Slice files directly in C++. In a 225 MB test mod, ZIP to ZIP went from about 1.5 s to 0.75 s on desktop. RAR and 7z mods, iOS and the web keep the previous path.
- **Converted scripts are always on**: converted scripts no longer wait for the countdown to start working. Every callback sets the script up the first time it runs in a song, so scripts also work when a song starts in the middle, restarts, or is played from the Chart Editor. A Psych `close()` now only stops the script until the song ends; before, it switched the script off for every later song too.
- **Script converter fixes from the Funkin source**: `triggerEvent` now fires the real V-Slice events (`Hey!` plays `hey` on BF and `cheer` on GF, `Set GF Speed` becomes `SetTargetBopSpeed`, `Play Animation` uses Psych's target rules), the Alt Idle Animation and Play Animation event scripts pick the same character Psych does, and imports use the runtime class paths the base game uses (`funkin.data.song.SongEventData`, `flixel.text.FlxTextBorderStyle`). Hey! events in charts play `cheer` on the girlfriend instead of a missing `hey` animation.
- **Test in Friday Night Funkin'**: after a mod converted to V-Slice is saved, a new button switches to the game. On Android it writes the mod straight into the game's `mods` folder through FNF's own file provider (the first time you pick the FNF folder and tap "Use this folder"; V-Converter remembers it), adds a `_polymod_meta.json` when the output has none, then opens Friday Night Funkin' (or its store page when it isn't installed). On Windows, Linux and macOS it finds the game (or asks for its folder once, changeable in Preferences), copies the mod into its `mods` folder and opens it. The new C++ library V-Launcher does the searching, copying and launching.
- **V-Touch in C++**: the touch engine was rewritten in C++ (no exceptions, RTTI or STL, just a C API) and runs through JNI on Android and desktop and as a static library on iOS; the web runs an identical Kotlin port. It handles the hitbox and virtual pad for 1 to 9 lanes, taps, double taps, long presses, menu dragging with flick scrolling, swipe back and pinch to zoom. New option: Flick To Scroll.
- **V-MiniAudio 0.2**: native Ogg Vorbis decoding (faster song loading on Android and desktop), cubic resampling, volume fades, loop points, sample-accurate delayed starts, equal-power panning, 8 mixer buses with low-pass, high-pass and echo, a smooth peak limiter instead of hard clipping, and peak/RMS meters.
- **Skins in JSON**: the title screen, the main menu and the back button now read `data/ui/title.json`, `data/ui/mainMenu.json` and `data/ui/backButton.json`. They set every sprite's image, position, anchor, scale, tint, layer and animations (prefix, fps, loop, indices, offsets), beat-synced dances, the intro text script, flashes and timings, the menu buttons' order, hidden buttons and per-button overrides, extra decorative sprites and the version text. A broken file falls back to the built-in look.
- **XML Editor** in the Generator, in the style of FNF's debug editors: add .png frames (idle0000.png, idle0001.png… become the "idle" animation) or one image that holds every frame (found automatically or by grid), preview the animations with onion skin, rename and reorder them, then generate the packed spritesheet .png with its Sparrow .xml. It trims empty borders, reuses repeated frames and can also write only the .xml for an image you already have.
- **Online menu** like FNF's Freeplay: Mod Gallery, Public Rooms, Share a Mod and News in the Alphabet font with health icons, a background that changes color with the selection and an info box in the corner. Search, engine and sort change with Enter, Left and Right.
- **Automatic server**: the online features (mods, rooms, news, Discord login, error reports) connect by themselves to the fastest V-Converter server in the official list, with no address to type. Typing your own server in Options still works and wins over the automatic one.
- **Options** split into **Preferences** (FPS counter, sounds, music, V-Slice layout, online server, error reports) and **Login To Discord**.
- Phones and tablets run in landscape only.
- Every button, toggle, checkbox and list choice plays `scrollMenu` when you select it (UI Sounds option).

## Editors

- The Chart, Character, Stage and Week editors now look like the base game's editors: a menu bar on top (File, Edit, Audio, View, Window, Test, Help) and toolboxes you can drag around, open and close from **Window**, with the chart, character, stage or story menu filling the rest of the screen.
- **Health icons** are now separate files in `images/icons/` (`icon-bf.png`, `icon-dad.png` and the rest, cut from the base game icon grid), and the Chart Editor shows the opponent's and player's icons above the grid.

## Touch

- **V-Touch**, the new touch framework: PlayTest has an FNF mobile style **hitbox** or a **virtual pad** (Options → Touch Controls, with opacity), the chart, stage and character editors zoom with a pinch and move with two fingers, a long press on a note or event opens its menu, and swiping right goes back in the menus.

## Interface

- **V-ConverterUI**, one component library (theme, buttons, cards, chips, fields, status banners, reports) shared by Android, desktop, iOS and the web instead of a copy per platform.

## Chart Editor

- Rebuilt as FNF's ChartingState, full screen on a 1280x720 stage: the 8-lane checkerboard grid of the current section with the camera following the strumline, the character icons (or names) above it, the white dummy arrow under the mouse, the time / section text at the top right and the Song / Section / Note tab box.
- ChartingState controls: click places a note, click a note deletes it, Ctrl+click selects it, Shift places off the grid, Ctrl places a mirrored note, A/D or Left/Right change section (Shift jumps 4), W/S scroll (Shift jumps 2 steps), R resets the section (Shift goes to the start), Q/E change the selected hold, Tab switches tabs, Space plays, Enter playtests, the wheel scrolls, Esc goes back to the main menu. On touch, drag to scroll and long press a note for its menu.
- Section tab: Must hit section (FocusCamera events), Change BPM and Section BPM (timing changes), Copy last section, Clear, Swap section and Alt Animation; Song tab: name, Save, Reload Audio, Reload JSON, load autosave, BPM, speed, characters and difficulty; Note tab: sustain length and Apply.
- Leaving a menu now fades to black like FNF's transitions instead of showing the pink background.

## Discord

- **Login To Discord** shows your Discord name and avatar in the menus. The online server does the login, so the server needs `DISCORD_CLIENT_SECRET` set (see the server README).
- **Discord status** on Windows, Linux and macOS: what you are converting or editing shows on your Discord profile while the Discord app is open. It can be turned off in Preferences.

## V-Slice

- **V-Slice Preview (Public PlayTest)** option: V-Slice output uses the new layout (`gameplay/songs`, `gameplay/characters`, `gameplay/stages`, `ui/story-mode`), and PlayTest mods are read as input.

## Audio

- Songs are mixed by V-MiniAudio, our own audio library, on every platform.

## Notes

- The Android APK is signed with the same keystore as before, so it installs as an update.
- The macOS app isn't notarized: the first time, right-click it and choose **Open**.
- RAR and 7z archives can't be opened on iOS or Apple Silicon Macs; extract them first or use a `.zip`.
